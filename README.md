# CPTF 购物助手

为 `COMICUP CITYTOUR FU`（CPP 活动 ID `7166`，展品活动 ID `7940`）制作的离线购物清单。

## 已完成

- 公开版默认使用空白清单，个人心愿单只保存在各自浏览器或备份文件中
- 三个核心页面：心愿单、摊位、备忘；数据管理收纳于设置
- 按创作摊、壹馆、贰馆、叁馆、肆馆和摊位号整理，不推断实际街道或相邻关系
- 搜索、状态筛选、热度/路线排序
- 价格、数量与购买状态保存在当前浏览器
- 离线逛展备忘：无料、盖章、摊宣链接与普通提醒
- 摊位模式：同一摊位集中处理展品、价格和备忘
- 制品可拖动调整顺序，重点摊位可加星并自动置顶
- 支持“已放弃”状态，也可删除不再需要的制品
- 详情图片按原比例完整显示，并可从电脑或手机添加、更换图片
- 手动添加的图片会压缩后内嵌进本地数据与 JSON 备份，换设备恢复后仍可查看
- 备忘类型可新增、改名或删除，已有备忘也能随时编辑
- 备忘支持上传整张摊宣并调整截取范围，截取图会进入离线备份
- 心愿单支持列表与双列，整理工具另提供漂亮大图
- 购买意向分为必买、想买、纠结和只逛逛；只逛逛不计入计划预算
- “整理心愿单”页面支持逐件快速标记、筛选未整理项目和批量设置意向
- 手机底部提供快速查摊位和“现场记一笔”，支持整笔加购、金额与照片离线备份
- 可设置个人逛展日；制品不再绑定容易变化的计划时段
- 摊位支持备注、多个安全社媒主页链接，以及无制品摊位的手动关注
- 摊位可标记未到达、已逛、返场、排队、摊主暂离或跳过
- 预算拆分为计划金额、纠结备选、实际消费和未定价数量
- 图片同步报告：成功匹配、图片更新与未匹配条目
- 展品详情页：封面、作者、社团、热度与 CPP 原链接
- 导入 CPP 导出的 `.xlsx` 并合并更新
- CPP 同步书签：自动比较完整查询范围、分页重试、按编号去重，并输出完整性报告
- 导入图片/描述补全 JSON
- 内置 20115 件 CPTF 公开制品资料库；导入 Excel 后自动匹配图片、作者和热度
- JSON 备份与恢复
- PWA 离线缓存

## 本地运行

这是一个无构建步骤的静态网站。不要直接双击 `index.html`，请在项目目录启动静态服务器：

```powershell
python -m http.server 4174
```

然后访问 `http://127.0.0.1:4174/`。

## 图片与描述补全

CPP 的展品搜索接口依赖登录态，不应在公开网页中收集用户名或密码。打开网站的“导入与同步 → 打开图片同步助手”，把按钮保存成浏览器书签，再在已登录的 CPP 活动页点击该书签。它会下载可直接导入的 JSON。

同步书签只在 `allcpp.cn` 页面内执行，使用浏览器已有 Cookie；代码不读取或导出 Cookie。当前版本获取搜索接口已经公开展示的封面、作者、社团、热度、摊位和展品编号。

也可以手工制作补全 JSON，字段示例见 `data/enrichment.example.json`。

匹配顺序：

1. `cppId`
2. `booth`（或 `boothRaw`）与 `name` 的组合

后续可增加只在本机运行的同步助手，复用浏览器中已有的 CPP 登录会话，把公开展品字段导出成该 JSON 格式。

## 数据说明

- 活动日期：2026-11-06 至 2026-11-08
- 场地：海峡国际会展中心
- 官方场地图在开发首版时尚未公布，因此项目没有伪造摊位坐标；地图发布后再追加精确布局。
- 购买状态、价格和补全信息默认只写入浏览器 `localStorage`。

项目基于 [Riiiiiii/cpg08-shopping-assistant](https://github.com/Riiiiiii/cpg08-shopping-assistant) 的离线购物助手思路重制，并保留原仓库许可证。
