# CPTF 逛展购物助手

为 **COMICUP CITYTOUR FU** 制作的手机优先、离线可用的逛展清单。它把心愿制品、摊位资料、无料/盖章备忘和现场消费放在同一个本地工具里。

- 在线使用：<https://whaleaugen.github.io/cptf-shopping-assistant-app/>
- 演示模式：<https://whaleaugen.github.io/cptf-shopping-assistant-app/?demo=1>
- 当前应用版本：**v0.28.1**
- 公共制品资料：**20,758 件，更新至 2026-10-30**

> 这不是 CPP 官方项目。制品、摊位与热度等公开资料可能变化，请以活动方和摊主最新公告为准。

## 快速开始

首次打开时，可以：

1. 导入 CPP 导出的 `.xlsx` 心愿单；
2. 恢复以前导出的 JSON 备份；
3. 或直接关注一个摊位、手动添加制品。

导入后会使用仓库中的公共资料库自动补全封面、作者、社团、热度等信息。价格、购买意向、星标、备忘和现场账本均由使用者自行维护。

## 主要功能

### 心愿单

- 列表与双列画廊视图，手机端可用悬浮按钮随时切换。
- 综合、最近加入、按摊位、按热度、按名称与“我的顺序”。星标制品始终优先展示。
- 独立右侧筛选器，支持意向、购买状态、馆别、原作/IP、制品类型和星标筛选。
- 购买意向：必买、想买、纠结、无料、只逛逛；支持逐件快速整理和批量设置。
- 支持 CPP 导入制品和手动补录制品；手动制品可修改名称、摊位、老师/社团、原作和类型。
- 支持本地图片、自定义价格、数量及待购买/已购买/已完售/已放弃状态。

### 摊位与备忘

- 按创作摊、壹馆、贰馆、叁馆、肆馆和摊位号整理；不推断真实距离或虚构路线。
- 摊位状态：未到达、已逛、需要返场、排队中、摊主暂离、已跳过。
- 同一摊位集中查看待买制品、无料、盖章、其他备忘和消费记录。
- 可手动关注普通摊位，也可单独加星为重点摊位；取消关注不会删除关联数据。
- 摊位名称、备注和多个老师/社团主页可分别维护，保存的主页链接直接可见。
- 备忘支持无料、盖章、摊宣和自定义类型；可从摊位详情直接新增或编辑。
- 摊宣图片可保留整张或裁剪，点击后可放大查看长图。

### 现场记账与预算

- 手机底部保留“查摊位 / 记一笔”快捷栏。
- 一笔消费只记录一次实际付款，可关联本次买到的心愿制品，不会重复累计金额。
- 支持编辑金额、摊位、备注、照片和关联制品，并提供摊位消费汇总。
- 可标记“包含代购”；代购金额未知时进入待核算，并保守占用预算。
- “个人已花”只来自现场消费账本；心愿单计划金额单独提示，不与真实支出混算。

## 数据、备份与隐私

- 正式数据默认保存在当前浏览器的 `localStorage`，仓库和公共网页不会保存个人心愿单。
- 演示模式使用独立存储空间，不会读取或覆盖正式数据。
- JSON 备份是最稳定的迁移方式，也适合保存图片较多的存档。
- 跨设备迁移会在本机使用 **AES-GCM** 加密后再上传临时密文；16 位迁移码用于派生密钥，不会随存档上传。
- 迁移码有效期为 **72 小时**，单个明文存档上限约 **17 MiB**；网络不稳定或无法连接迁移服务时，请改用 JSON 备份。
- 恢复 JSON 或迁移码前会保存本机快照，恢复后 24 小时内可以撤销。
- 迁移恢复成功后会尝试删除云端临时副本；如果删除失败，界面会如实提示并提供重试入口。

请妥善保管 JSON 文件和迁移码。迁移码等同于临时存档钥匙，不要发给无关人员。

## 公共资料库与 CPP 同步

仓库内置 `data/cptf-catalog.json`，当前包含 20,758 件 CPTF 公开制品资料。匹配优先使用 `cppId`，其次使用摊位号与制品名称组合；自动补全不会覆盖个人价格、意向、购买状态或自定义图片。

CPP 的展品接口依赖登录态，公开网页不会收集 CPP 用户名、密码或 Cookie。需要自行更新资料时，可使用设置中的同步助手/书签在已登录的 CPP 页面生成 JSON，再导入购物助手。

## 本地运行

这是一个无构建步骤的静态 PWA。不要直接双击 `index.html`，请在项目目录启动静态服务器：

```powershell
python -m http.server 4174
```

然后访问 <http://127.0.0.1:4174/>。如果系统没有 Python，也可以使用任意静态文件服务器。

## 项目结构

- `index.html`：页面结构与对话框
- `styles.css`：响应式界面样式
- `app.js`：本地数据、导入、筛选、摊位、备忘、账本和迁移逻辑
- `data/cptf-catalog.json`：公共制品资料库
- `service-worker.js`：PWA 离线缓存
- `sync-helper.html` / `sync-bookmarklet.js`：CPP 公开资料同步助手
